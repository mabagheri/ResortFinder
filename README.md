# ResortFinder

A tool to find the best all-inclusive resort for a trip.

## Planned features

1. **Rating filter**: list every hotel in an area (e.g. Cancun) and keep only those rated at least X
   (e.g. 4.5) on Expedia, TripAdvisor, Booking.com and Google Maps.
2. **Cheapest stay window**: for a time period (e.g. two months), check every possible m-night stay
   (e.g. 4 nights) on several sites (Booking.com, Expedia, ...) and return the cheapest option.
